What you change

The combine and its base values go together

The kind of question decides the combine, and the combine decides what the base cases return. Optimizing needs a value that can never win as its "invalid" answer.

Number of choices

Climbing Stairs has two hard-coded calls. When the choices depend on the input, such as one per coin or per matching word, the two calls become a loop or a map over the choices.

Shape of the state

A grid needs (row, col), so the memo key becomes an array like memo[[r, c]]. Key on the values that change. Data like nums or coins stays out of the key.

Payoff per choice

When a choice carries a cost or gain, such as nums[i] or cost[i], add it before combining: cost[i] + min(...).

Cost of a memoized DP: the number of distinct states, times the work done per state. Climbing Stairs has n states and 2 choices each, so O(n).

Limits

Where the skeleton fits less well

Best result ending at i

Longest Increasing Subsequence and Maximum Subarray define the state as "best ending at index i", and the answer is the best over all i. There is no single top call, so a bottom-up loop fits better.

Extra state

Stock problems with a cooldown need to know whether you are holding a share. That adds a part to the state and to the memo key.

Overshoot checks

The n < 0 check is specific to Climbing Stairs. Other problems need their own bounds checks, such as an index past the end of an array.

Ruby notes

Two details that bite

Use key?, not ||=

||= recomputes whenever the stored value is false or nil. Word Break caches false answers, so it needs key?.

Default memo argument

The default {} is created fresh on each top-level call, so you can pass memo down without a wrapper method.

Practice order

Stretch the template one change at a time

  1. House Robber. Same shape as Climbing Stairs. Only the combine changes, to a max with a payoff.
  2. Coin Change. Adds a loop over choices and the min-with-Infinity base case.
  3. Decode Ways. Conditional choices on a string index.
  4. Word Break. A boolean answer, and the key? caching detail.
  5. Unique Paths. A two-part state, if you want the grid version.
