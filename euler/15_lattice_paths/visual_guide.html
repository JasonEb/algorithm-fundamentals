Counting paths once

Every route through the grid is a sequence of right/down moves. V1 walks every full route separately; V2 notices that routes converge on the same intersections, over and over.

V1: the recursion tree, and where it overlaps

For a 2×2 grid, count_paths(right, down) gets called on (1, 1) from two different branches — it doesn't know that, so it does the same work twice.

V2: fill the grid once, bottom-up

Every cell's path count is just the cell above plus the cell to the left — the same relationship Pascal's triangle uses.

Both versions

def lattice_paths(grid_size)   # V1
    count_paths(grid_size, grid_size)
end

def count_paths(right, down)
    return 1 if right == 0 || down == 0
    count_paths(right - 1, down) + count_paths(right, down - 1)
end
def lattice_paths(grid_size)   # V2
    paths = Array.new(grid_size + 1) { Array.new(grid_size + 1, 0) }

    row = 0
    while row <= grid_size
        col = 0
        while col <= grid_size
            paths[row][col] = (row == 0 || col == 0) ? 1 :
                paths[row - 1][col] + paths[row][col - 1]
            col += 1
        end
        row += 1
    end

    paths[grid_size][grid_size]
end
