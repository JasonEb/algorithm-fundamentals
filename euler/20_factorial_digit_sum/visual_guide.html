Growing, then peeling

Same shape as power_digit_sum: build a huge number first (10! = 3628800), then sum its digits — the only question is whether that second step goes through a string.

Step two is where they differ

Both versions

def factorial_digit_sum(n)   # V1
    factorial = 1
    i = 2
    while i <= n
        factorial *= i
        i += 1
    end

    sum = 0
    factorial.to_s.each_char { |digit| sum += digit.to_i }
    sum
end
def factorial_digit_sum(n)   # V2
    factorial = 1
    i = 2
    while i <= n
        factorial *= i
        i += 1
    end

    sum = 0
    while factorial > 0
        sum += factorial % 10
        factorial /= 10
    end
    sum
end
