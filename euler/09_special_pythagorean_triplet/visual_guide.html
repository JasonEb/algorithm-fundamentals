Collapsing the search

V1 searches a grid of (a, b) pairs. But b isn't actually free to search — once a and the perimeter are fixed, b is already determined. V2 just solves for it.

V1: searching a full grid

For each a, try every b and derive c from the perimeter — O(n²) pairs checked.

V2: b was never free

Two equations, two unknowns once a is picked: a + b + c = perimeter and a² + b² = c². Solving them together gives b directly.

def special_pythagorean_triplet(perimeter)   # V1
    a = 1
    while a < perimeter
        b = a + 1
        while b < perimeter
            c = perimeter - a - b
            return a * b * c if c > b && a * a + b * b == c * c
            b += 1
        end
        a += 1
    end
    nil
end
def special_pythagorean_triplet(perimeter)   # V2
    a = 1
    while a < perimeter
        numerator = perimeter * (perimeter - 2 * a)
        denominator = 2 * (perimeter - a)

        if denominator != 0 && numerator % denominator == 0
            b = numerator / denominator
            c = perimeter - a - b
            return a * b * c if b > a && c > b
        end
        a += 1
    end
    nil
end
