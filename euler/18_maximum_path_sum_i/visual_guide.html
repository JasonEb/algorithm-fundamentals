Ruby · brute-force paths → bottom-up collapse

Collapsing the triangle

Same triangle, worked in opposite directions: V1 walks every path from the top down; V2 starts at the bottom and folds each row into the one above it.

The example triangle

V1: try every path from the top

16,384 possible routes through 15 rows, brute-forced by recursion. Notice: two different paths through 4 (row 3) and 6 (row 3) both continue down through the same cells below them — recomputed independently every time.

V2: fold from the bottom up

Each cell becomes itself plus whichever of the two cells below it is bigger. Do this row by row, and the top cell ends up holding the answer for the whole triangle.

Both versions

def max_path_sum(triangle)   # V1
    find_max(triangle, 0, 0)
end

def find_max(triangle, row, col)
    value = triangle[row][col]
    return value if row == triangle.length - 1
    left = find_max(triangle, row + 1, col)
    right = find_max(triangle, row + 1, col + 1)
    value + [left, right].max
end
def max_path_sum(triangle)   # V2
    rows = triangle.map(&:dup)

    row = rows.length - 2
    while row >= 0
        col = 0
        while col < rows[row].length
            rows[row][col] += [rows[row + 1][col], rows[row + 1][col + 1]].max
            col += 1
        end
        row -= 1
    end

    rows[0][0]
end
