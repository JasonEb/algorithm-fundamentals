Ruby · string conversion → arithmetic

Peeling digits

215 = 32768. Both versions sum its digits — the difference is whether Ruby builds a string to do it, or you peel digits off arithmetically.

V1: convert to a string, walk the characters

32768.to_s gives "32768", then each character gets converted back to an integer and added up.

V2: peel digits with % and /

No string at any point — % 10 reads the last digit, integer / 10 drops it, repeat until nothing's left.

Both versions

def power_digit_sum(exponent)   # V1
    num = 2 ** exponent
    sum = 0
    num.to_s.each_char { |digit| sum += digit.to_i }
    sum
end
def power_digit_sum(exponent)   # V2
    num = 2 ** exponent
    sum = 0
    while num > 0
        sum += num % 10
        num /= 10
    end
    sum
end
