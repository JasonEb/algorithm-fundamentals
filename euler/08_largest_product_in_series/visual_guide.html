Sliding the window

V1 recomputes the product of every window from scratch. Most of that work is wasted — each window shares all but one digit with its neighbor.

V1: every window, computed independently

For digit string "9989" with a window of 2, each position multiplies its own two digits from nothing.

V2: carry the product forward

Instead of recomputing, divide out the digit leaving the window and multiply in the digit entering it — reusing everything that didn't change.

The zero case, traced

For "1023" with a window of 2: the window containing the 0 can't be divided through normally.

def largest_product_in_series(digits_string, series_length)   # V1
    digits = digits_string.chars.map(&:to_i)
    largest = 0

    start = 0
    while start <= digits.length - series_length
        product = 1
        i = start
        while i < start + series_length
            product *= digits[i]
            i += 1
        end
        largest = product if product > largest
        start += 1
    end

    largest
end
def largest_product_in_series(digits_string, series_length)   # V2
    digits = digits_string.chars.map(&:to_i)

    product = 1
    zero_count = 0
    i = 0
    while i < series_length
        zero_count += 1 if digits[i] == 0
        product *= digits[i] if digits[i] != 0
        i += 1
    end
    largest = zero_count == 0 ? product : 0

    start = 1
    while start <= digits.length - series_length
        leaving = digits[start - 1]
        entering = digits[start + series_length - 1]

        leaving == 0 ? zero_count -= 1 : product /= leaving
        entering == 0 ? zero_count += 1 : product *= entering

        current = zero_count == 0 ? product : 0
        largest = current if current > largest
        start += 1
    end

    largest
end
