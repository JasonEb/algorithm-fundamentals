Building the palindrome search

The problem: find the largest palindrome that's the product of two n-digit numbers. Before reaching for anything clever, here's the reasoning that gets you to a correct, if brute-force, first solution.

The build-up, step by step

  1. Define the search space

    "Two n-digit numbers" means both factors range from the smallest n-digit number to the largest. For digits = 2, that's 10 through 99 — min = 10^(digits-1), max = 10^digits - 1.

  2. Decide what counts as one candidate pair

    A product comes from a pair of numbers, a and b. Since a × b equals b × a, checking (91, 99) and later (99, 91) would just repeat the same work. Constraining b ≥ a checks every distinct pair exactly once.

  3. Define the check itself: what makes a number a palindrome

    A palindrome reads the same forwards and backwards. The most direct way to check: convert the number to a string and compare it against its own reverse. 9009.to_s == 9009.to_s.reverse — both sides read "9009", so it matches.

  4. Track the best one seen so far

    Since you're checking every pair regardless (nothing to skip yet in the naive version), keep a running largest value, and update it whenever a product is both a palindrome and bigger than what you've already found.

The naive solution

def largest_palindrome_product(digits)
    min = 10 ** (digits - 1)
    max = (10 ** digits) - 1
    largest = 0

    a = min
    while a <= max
        b = a
        while b <= max
            product = a * b
            largest = product if palindrome?(product) && product > largest
            b += 1
        end
        a += 1
    end

    largest
end

def palindrome?(num)
    num.to_s == num.to_s.reverse
end
