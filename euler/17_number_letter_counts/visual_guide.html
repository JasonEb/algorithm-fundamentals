Words into numbers

Both versions break a number into parts — hundreds, tens, ones — using the same lookup tables. The difference is whether you build the actual word and measure it, or just add up known lengths directly.

Breaking 342 into parts

"three hundred and forty-two" is really four pieces glued together.

V1: build the word, then measure it

Concatenates each part into an actual string ("threehundredandfortytwo"), then takes .length at the end.

V2: skip the string, add up known lengths

ONES_LEN and TENS_LEN store the length of each word part directly — "three" is just the number 5, never the characters t-h-r-e-e.

Both versions

ONES = ["", "one", "two", "three", ...]   # V1
TENS = ["", "", "twenty", "thirty", ...]

def word_length_for(n)   # (via words_for(n).length)
    words = ""
    words += ONES[n / 100] + "hundred" if n >= 100
    # ...
    words
end
