Narrowing the search

Same problem, same original brute-force shape — but reworked so the search only ever visits candidates that could possibly be right, instead of walking through every integer down from n!.

The journey, in three stages

Same two building blocks throughout — a search over candidates, and a divisibility check — but what they search over and check changes completely by the end.

1. Original (iterative)
def divisible_by_all?(n, num)
  while n != 1
    return false if
      num % n != 0
    n -= 1
  end
  true
end

def smallest_multiple(n)
  product =
    (1..n).reduce(1) { |a,x| a*x }
  limit = product
  while limit > 0
    if divisible_by_all?(n, limit)
      product = limit
    end
    limit -= 1
  end
  product
end
2. Recursive, same search space
def divisible_by_all?(n, num)
  while n != 1
    return false if
      num % n != 0
    n -= 1
  end
  true
end

def search(n, limit, product)
  return product if limit == 0
  product = limit if
    divisible_by_all?(n, limit)
  search(n, limit - 1, product)
end

def smallest_multiple(n)
  product =
    (1..n).reduce(1) { |a,x| a*x }
  search(n, product, product)
end
3. Recursive on n, narrowed search
divisible_by_all? — gone

def search(n, limit, prev_answer)
  return limit if limit % n == 0
  search(n, limit + prev_answer,
         prev_answer)
end

def smallest_multiple(n)
  return 1 if n == 1

  prev_answer =
    smallest_multiple(n - 1)
  search(n, prev_answer, prev_answer)
end

Call stack for smallest_multiple(3)

Descends to the base case first, then each level runs its own narrowed search using the level below's answer as prev_answer.

The candidate space, before and after

For n = 5, the original approach's candidate space is every integer from 1 to 5! = 120. The narrowed version only ever visits multiples of prev_answer (12) — five candidates, not a hundred and twenty.

The final code

def search(n, limit, prev_answer)
  return limit if limit % n == 0
  search(n, limit + prev_answer, prev_answer)
end

def smallest_multiple(n)
  return 1 if n == 1

  prev_answer = smallest_multiple(n - 1)
  search(n, prev_answer, prev_answer)
